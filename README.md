# ✦ Lumina — Partagez l'inspiration

Un espace minimaliste et inspirant où chacun peut créer un profil et partager des pensées, des gratitudes ou des rêves.

> « La lumière que tu cherches est déjà en toi. »

## ✨ Fonctionnalités

- **Création de profil** : pseudo, bio courte et couleur d'âme
- **Discussion libre** : messages inspirants
- **Cercle actif** : liste des membres du cercle
- **Éclats du jour** : citations rotatives pour nourrir l'esprit
- Design sombre élégant, mobile-first, fluide

> **Note** : Version pure front-end (localStorage). Parfaite pour GitHub Pages. Pour une vraie messagerie multi-utilisateurs en temps réel, on peut ajouter Firebase plus tard.

## 🚀 Site en ligne

## 📱 Utilisation

1. Ouvre le site
2. Crée un profil ou rejoins
3. Partage une pensée
4. Partage le lien avec d'autres
